# Brand Direction — Applied AI Firm

Working notes for the AI consultancy brand. Open **`brand-direction.html`** in a browser
for the visual one-pager; this file captures the reasoning behind it.

## The brief

- **Client focus:** mid-to-large enterprise.
- **Business shape:** starts as a personal brand (founder-fronted), built to scale into a
  firm — so the brand stands on its own, not a personal name.
- **Aesthetic reference:** Hermes (AI agents), OpenAI, ElevenLabs — "high-grain tech":
  editorial restraint, near-monochrome, film grain, simple geometric marks, lab-grade
  credibility over SaaS enthusiasm.

## Positioning spine

> **Frontier AI, measured in outcomes.**
> An applied AI firm that builds and ships solutions accountable to realised ROI —
> not advisory decks, not pilots that die in committee.

- Stance: **operator**, not advisor. "We put our name on the outcome."
- Against: hype-merchants, endless pilots, "AI strategy" theatre, one-size SaaS,
  fear-driven adoption.

## Naming — where we landed

The real-word lane is **exhausted** in AI. Vetted live and ruled out for collisions in or
near the space: Delta, Praxis, Compound, Throughline, Forge, Quotient, Caliber, Upshot,
Tenet, Provenir, Reditus, Certo. Conclusion: commit to coinage / rare words (the
Anthropic / Cohere / Mistral route), which is also what the reference brands did.

### Finalists (both vetted clear)

| Name | Origin | Read |
|------|--------|------|
| **Outturn** | real word: "the quantity produced; the result" | grounded, operator, anti-hype; the safe anchor |
| **Redix** | coined from Latin *reditus*, "return" (→ ROI) | sharp, technical, "AI-lab"; closest to the references |
| **Avalent** *(outside option)* | Latin *valere*, "to be worth" | premium/abstract, but mild trademark risk (small semiconductor firm) |

## Visual system (v0.1)

- **Type:** display serif (Instrument Serif → licensed: Reckless / Editorial New) +
  grotesque (Schibsted Grotesk → licensed: Söhne / Aeonik) + mono for data (Space Mono).
- **Colour:** near-monochrome + warm. Ink `#141210`, Paper `#ECE7DE`, single **ember**
  accent `#C7552F`. Deliberately **no AI-blue**.
- **Texture:** film-grain overlay is the signature — humanises the frontier.
- **Voice:** understated, specific, never salesy. Killed: "AI that pays for itself."
